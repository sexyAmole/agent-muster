# 10 分钟接入 IM

目标：让一条来自钉钉、飞书或企业微信的任务消息，在同一聊天中收到 Agent 回复。预计 10 分钟，不含组织管理员审批、平台发布和模型响应等待时间。

## 0:00—2:00：准备本地任务环境

先按 [5 分钟完成第一个任务](./first-task.md) 添加项目，确认目标 Agent 已安装、登录且能执行任务。准备对应平台的手机应用与创建应用的权限。电脑和 Agent Muster 在接入及接收任务期间都需要保持运行、联网。

![确认 Agent 安装状态](../screenshots/agent-management.jpg)

## 2:00—5:00：扫码创建应用

在侧边栏打开「IM 集成」，选择一个平台的页签，点击「扫码创建应用」。使用该平台手机应用扫码，按页面提示完成创建和授权。二维码过期时重新获取；没有组织权限时请管理员处理后再继续。

![IM 集成中的平台页签和扫码创建入口](../screenshots/im-integration.jpg)

服务通过 SDK 长连接接收消息，无需公网 Webhook 地址。教程截图展示接入前的入口；接入后出现对应应用条目。

## 5:00—7:00：绑定项目和 Agent

在新应用条目中选择已添加的项目、可用的 Agent 和合适的权限模式。钉钉、飞书可通过「一键同步」同步名称与图标；飞书、企业微信检查消息监听是否已连接。

配置修改后再次核对绑定项目。更改项目或 Agent 会清空该应用所有聊天的会话绑定及项目、模型配置，下一条任务会创建新对话。

## 7:00—9:00：发送第一条任务

先在机器人单聊中发送 `/status`，核对项目、Agent 和模型，再发送：

> 只阅读这个项目的 README，告诉我如何启动项目，不修改文件。

收到回复后继续追问一句，确认聊天可以继续同一任务。然后再尝试群聊：将机器人加入群聊并提及机器人发送任务。同一群聊共享项目配置与会话。

![本地会话中的 Agent 任务界面](../screenshots/agent-selector.jpg)

上图用于识别本地任务界面。IM 发起的任务也可在本地对话中查看执行状态，最终结果回到原 IM 聊天。

## 9:00—10:00：验收与排查

完成标准：`/status` 返回正确绑定，文本任务在原聊天收到回复，本地能找到该任务对话。

- 没有回复：确认电脑和服务运行、平台授权完成、Agent 可执行；飞书和企业微信检查连接状态，群聊检查是否提及机器人。
- 任务仍在执行：在本地对话查看日志；同一聊天的消息与指令按顺序处理。
- 飞书图片下载失败：开通 `im:message:readonly` 权限并发布应用版本后重试。首次验收建议先用文本。
- 想重新开始：发送 `/new`，再发送任务；历史记录保留。

应用凭证保存在本地 `.agent-muster/im/` 下，不要分享配置文件或包含凭证的截图。删除本地接入会停止监听并保留对话记录，不会删除平台应用。完整指令见 [IM 使用说明](../../README.zh-CN.md#im-集成)。
