# 5 分钟完成第一个任务

目标：在本地项目中完成一条任务，找到执行结果并检查 Git 变更。预计 5 分钟，不含 Agent 安装、登录和模型响应等待时间。

## 0:00—1:00：准备与添加项目

从 [最新 Release](https://github.com/sexyAmole/agent-muster/releases/latest) 的 Assets 下载对应系统和芯片的安装包，安装并打开。先确认至少一个 Agent CLI 已安装、登录，在「Agent 管理」中可以检测到。模型权限和费用由对应服务管理。

![Agent 管理中的安装状态](../screenshots/agent-management.jpg)

点击左侧「项目」旁的添加按钮，选择一个可修改的本地 Git 仓库。确认项目名称和目录正确，建议先用自己的练习项目。

## 1:00—2:00：选择 Agent

点击项目旁的「新建对话」，在输入区确认项目、已安装的 Agent、模型和权限。需要修改文件时，选择允许当前项目写入的权限；Codex 的相关模式需要开启沙箱。

![任务输入区的项目、Agent、模型和权限选项](../screenshots/agent-selector.jpg)

## 2:00—3:00：创建任务

输入并发送：

> 查看 README 的启动说明。如果缺少运行前提，请补充一句准确的说明，只修改 README；完成后说明修改原因。如果内容已完整，请解释为何无需修改。

观察回复、工具调用和执行状态。需要补充要求时，在同一对话继续发送。任务完成时间取决于 Agent 和模型，超过预估时可继续等待或停止任务。

## 3:00—4:00：多窗并行

使用「创建会话」旁的布局切换，选择双栏或四宫格。在另一窗口创建独立任务，例如「只阅读项目目录，解释主要模块」。每个窗口分别确认项目和 Agent；并行任务先分配不同文件，避免同时改写同一处内容。

![四宫格布局，每个窗口独立选择任务](../screenshots/multi-pane.jpg)

## 4:00—5:00：检查 Git 差异

打开会话旁的项目面板，从「文件」切换到「Git」，选择变更文件，查看已暂存与未暂存差异。确认只有预期文件发生变化；任务没有修改文件时，工作区可以保持干净。下图展示项目面板入口，Git 页签与文件页签相邻。

![项目面板及文件、Git、终端入口](../screenshots/project-files.jpg)

完成标准：能看到任务回复，能继续同一对话，并在 Git 面板确认变更或干净状态。审核通过后自行提交代码。

遇到未安装提示时，先在终端确认对应 CLI 可执行，调整 PATH 后重启应用；模型不可用时检查 CLI 登录和模型权限。更多说明见 [使用文档](../../README.zh-CN.md)。
